# Screenshots

There are currently no screenshots captured from a running Kronoza device or emulator in this repository. Images in `assets/design-references/aistudio/` are design references and must not be presented as screenshots of the shipped app.

When adding screenshots:

1. Capture the current app from a real Android device or emulator.
2. Use synthetic schedule/task content and remove personal notifications or profile details.
3. Save PNG files in `assets/screenshots/` using descriptive lowercase names, for example `home-dashboard.png` or `monthly-calendar.png`.
4. Link only those captured images in the README with repository-relative image paths.
5. Keep images representative of the current application version.

Do not create mock screenshots or reuse design mockups as though they were device captures.
