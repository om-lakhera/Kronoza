# Kronoza v1.0.0 Release Notes

**Version**: `1.0.0` (Version Code `1`)
**Developer**: Om Lakhera ([https://github.com/om-lakhera](https://github.com/om-lakhera))

## Highlights

Kronoza v1.0.0 is the initial production release of an offline-first, privacy-focused native Android calendar, task manager, reminder engine, and productivity tracker built with Kotlin and Jetpack Compose.

### Calendar & Scheduling
- Full **Month**, **Week**, **Day**, and **Agenda** views with accurate leap-year, DST, and month-boundary date calculations.
- Single-day, multi-day, all-day, and recurring events (`Daily`, `Weekly`, `Monthly`, `Yearly`) with occurrence-level or series-wide editing and deletion.
- Real-time schedule overlap detection in the Event Editor.

### Tasks & Subtasks
- Full task lifecycle with due dates/times, priority tiers (`High`, `Medium`, `Low`), categories, interactive subtasks, overdue detection, multi-criteria filters, and sorting.

### Native Reminders & Notifications
- Reliable `AlarmManager` exact reminders paired with `WorkManager` fallback scheduling.
- Automatic rescheduling after device reboot (`BOOT_COMPLETED`), package replacement, and timezone or system clock changes.
- In-app notification center with unread tracking and category filtering.

### Genuine Local Insights
- Focus hours, meeting totals, task completion rate, active/best streaks, category balance, and 4-week trend charts derived strictly from live on-device records.

### Backup, Security & Production Hardening
- Completely blank first-launch workspace with zero pre-populated demo events, tasks, or placeholder profiles.
- Offline JSON backup export and restore with SHA-256 checksum verification, payload size bounds, and Merge / Replace All modes.
- Zero `INTERNET` permission, zero analytics/tracking SDKs, and Android Photo Picker (`PickVisualMedia`) avatar support.
- R8 minification and resource shrinking enabled for compact release builds.
