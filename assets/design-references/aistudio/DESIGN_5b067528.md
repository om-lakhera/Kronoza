## Brand & Style

This design system is crafted for a premium, minimal Android calendar and productivity application. It targets busy professionals, students, and intentional planners who value clarity over visual noise. The emotional response is one of calm control—transforming dense schedules and task lists into an airy, approachable, and effortless daily rhythm.

The aesthetic blends **Minimalism** with **Corporate / Modern** Material 3 principles:
- **Generous Whitespace:** Layouts breathe with intentional margins and open vertical rhythm, preventing cognitive overload.
- **Soft Pastel Categorization:** Rather than harsh, saturated status colors, events and tasks use muted pastel fills paired with crisp, legible text.
- **Tactile Precision:** Rounded cards, subtle 1px borders, and restrained shadows create a clean, paper-like hierarchy tailored for touch interaction.

## Colors

The palette is anchored in a high-contrast light mode that prioritizes readability and visual calm:

- **Backgrounds & Surfaces:**
  - **Canvas (`#F8F9FB`):** Very light cool neutral used for the main app background.
  - **Elevated Surface (`#FFFFFF`):** Pure white for cards, bottom sheets, and navigation bars.
- **Typography & Ink:**
  - **Primary Text (`#111827`):** Crisp dark charcoal for headlines, event titles, and primary actions (exceeds WCAG AAA contrast on white).
  - **Secondary Text (`#6B7280`):** Muted slate for timestamps, metadata, and inactive navigation labels.
- **Semantic Pastel Accents:**
  - **Lavender (`#E9E5FF` container / `#7C69EF` accent):** Primary brand accent, active states, and focus/deep-work blocks.
  - **Sky Blue (`#E0F2FE` container / `#38BDF8` accent):** Secondary accent for meetings, collaborative events, and calendar indicators.
  - **Mint (`#DCFCE7` container / `#34D399` accent):** Tertiary accent for completed tasks, habits, and personal wellness.
  - **Soft Coral (`#FFE4E6` container / `#FB7185` accent):** High-priority alerts, deadlines, and urgent reminders.

## Typography

The typographic hierarchy pairs **Plus Jakarta Sans** for expressive, geometric headlines with **Inter** for highly legible body copy, timestamps, and UI labels.

- **Headlines:** Tight negative letter-spacing (`-0.01em` to `-0.02em`) gives date headers and screen titles a modern, editorial polish.
- **Tabular Numerals:** Enable `tabular-nums` on all timestamps, calendar dates, and countdowns so vertical timelines align cleanly.
- **Responsive Scaling:** On compact mobile viewports (`< 600dp`), `display-lg` steps down to `display-lg-mobile` (`28px`) to preserve horizontal breathing room.

## Layout & Spacing

The layout uses a **Fluid Grid** adapted to Android Material 3 window size classes:

- **Compact (Mobile `< 600dp`):** 4-column fluid grid with `1.25rem` (`20px`) outer margins and `1rem` (`16px`) gutters. Single-column vertical scrolling for timelines and task lists.
- **Medium (Foldables / Small Tablets `600dp – 839dp`):** 8-column fluid grid with `1.5rem` (`24px`) margins. Supports two-pane layouts (e.g., calendar month view alongside daily agenda).
- **Expanded (Tablets / Desktop `>= 840dp`):** 12-column fluid grid with `2rem` (`32px`) margins, transitioning bottom navigation to a persistent navigation rail.

All interactive elements strictly adhere to a minimum `48dp x 48dp` touch target, using `space-sm` (`0.5rem`) and `space-md` (`1rem`) for internal component padding and element gaps.

## Elevation & Depth

Visual hierarchy relies on **Tonal Layers** paired with **Low-Contrast Outlines** and **Restrained Ambient Shadows**:

- **Base Layer:** `#F8F9FB` canvas sits at elevation 0.
- **Card Layer:** `#FFFFFF` cards sit at elevation 1, defined by a subtle `1px solid rgba(17, 24, 39, 0.06)` border and a soft ambient shadow (`0 4px 16px rgba(17, 24, 39, 0.04)`).
- **Floating & Overlay Layer:** The Floating Action Button (FAB), bottom sheets, and active date pickers use a slightly stronger diffused shadow (`0 8px 24px rgba(124, 105, 239, 0.16)` for primary-tinted elements, or `rgba(17, 24, 39, 0.08)` for neutral surfaces) to clearly separate them from scrolling content.

## Shapes

The shape language is **Rounded** (`roundedness: 2`), creating a friendly, approachable, and modern Android aesthetic:

- **Cards & Event Blocks:** `1rem` (`16px`) to `1.25rem` (`20px`) corner radius.
- **Buttons & Inputs:** `0.75rem` (`12px`) corner radius for standard inputs and secondary buttons; full pill (`9999px`) for primary CTAs and filter chips.
- **Floating Action Button (FAB):** `1rem` (`16px`) squircle (Material 3 standard) or full circle (`9999px`) for quick-add actions.
- **Bottom Sheets & Dialogs:** `1.5rem` (`24px`) top corner radius.

## Components

- **Bottom Navigation Bar:** Fixed 5-tab bar (**Home**, **Calendar**, **Tasks**, **Insights**, **Settings**) on `#FFFFFF` with a subtle top border. Active tab uses `#7C69EF` icon/label with a soft `#E9E5FF` pill indicator; inactive tabs use `#6B7280`.
- **Floating Action Button (FAB):** Prominent `#7C69EF` container with `#FFFFFF` plus icon, positioned above the bottom navigation bar on the trailing edge. Minimum `56dp x 56dp` touch target.
- **Cards (Events & Tasks):** `#FFFFFF` background, `16px–20px` radius, `1px` subtle border, and `16px` internal padding. Calendar event blocks use pastel container fills (`#E9E5FF`, `#E0F2FE`, `#DCFCE7`, `#FFE4E6`) with `#111827` primary text.
- **Buttons:**
  - *Primary:* Solid `#7C69EF` fill, `#FFFFFF` label (`label-lg`), `48dp` height, pill or `12px` radius.
  - *Secondary:* `#F8F9FB` fill with `1px` border and `#111827` label.
- **Chips:** Pill-shaped (`9999px`), `32dp` height, `#F8F9FB` default fill, transitioning to `#E9E5FF` with `#7C69EF` text when selected.
- **Lists:** Clean `56dp–72dp` row height with `16px` horizontal padding, leading icon/checkbox, two-line text (`title-md` + `body-sm`), and trailing metadata.
- **Checkboxes & Radio Buttons:** `24dp` visual control inside a `48dp` touch target. Unchecked uses `1.5px` `#6B7280` stroke; checked animates to `#7C69EF` (or `#34D399` for completed tasks) with a crisp white checkmark.
- **Input Fields:** `#F8F9FB` fill, `12px` radius, `1px` transparent border that transitions to `#7C69EF` on focus, with `#6B7280` placeholder text.
