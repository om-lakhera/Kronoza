# Support

For help with Kronoza:

1. Check the [README](README.md) and the guides in [`docs/`](docs/).
2. For a reproducible defect, use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
3. For a product suggestion, use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).

Include the app version, Android version, device model, and clear reproduction steps when relevant. Do not attach private calendars, backup files, credentials, or keystores.

For a security issue, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
